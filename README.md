## 📖 Sobre o Projeto
O **Pegajogo** foi um marco na internet brasileira dos anos 2000. Antes da era das lojas de aplicativos modernas, ele servia como um hub centralizado que entregava centenas de jogos em Flash, executáveis e conteúdos multimídia diretamente no desktop de milhares de brasileiros.

Com o encerramento das atividades do site oficial, o ecossistema do Pegajogo tornou-se *abandonware*. Este repositório é uma iniciativa de **arqueologia digital** dedicada a documentar, preservar e, eventualmente, reconstruir a infraestrutura técnica que movia essa plataforma.

### 🎯 Objetivos do Repositório
- 💾 **Preservação:** Coletar instaladores, binários (.exe), DLLs e logs originais.
- 🏗️ **Engenharia Reversa:** Documentar o uso de Firebird SQL, conexões ODBC e chamadas de sistema.
- 🛠️ **Reconstrução:** Recuperar esquemas de banco de dados (.fdb / .gdb) e reconstruir a experiência do usuário.
- 🤝 **Comunidade:** Unir entusiastas de *retrocomputing* e desenvolvedores interessados em software legado.

### 🛠️ Estrutura
| Pasta | Descrição |
| :--- | :--- |

### 🚀 Como contribuir
Sua ajuda é fundamental para que essa memória não se apague!

1.  **Arquivos Antigos:** Se você tem um HD antigo com pastas do Pegajogo, procure por arquivos `.fdb`, `.gdb` ou o instalador original.
2.  **Análise Técnica:** Ajude a mapear as funções das DLLs ou a estrutura das tabelas SQL.
3.  **Memórias:** Tem screenshots ou histórias sobre o uso do software? Adicione na pasta `history`.
4.  **Issues:** Abra uma issue para discutir ideias de emulação ou preservação.

### 💡 Por que isso importa?
Preservar o software é preservar a cultura. O Pegajogo foi a porta de entrada para o mundo dos games para muitos brasileiros. Estudar como ele funcionava — desde a gestão de banco de dados local até a integração com Flash — é uma aula de história da engenharia de software nacional.
