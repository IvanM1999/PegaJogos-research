## 📖 About the Project
**Pegajogo** was a landmark in the Brazilian internet scene during the 2000s. Long before modern app stores, it served as a centralized hub that delivered hundreds of Flash games, executables, and multimedia content directly to the desktops of thousands of users.

Since the official website went offline, the Pegajogo ecosystem has become *abandonware*. This repository is a **digital archaeology** initiative dedicated to documenting, preserving, and eventually reconstructing the technical infrastructure that powered this platform.

### 🎯 Repository Objectives
- 💾 **Preservation:** Collect original installers, binaries (.exe), DLLs, and logs.
- 🏗️ **Reverse Engineering:** Document the use of Firebird SQL, ODBC connections, and system calls.
- 🛠️ **Reconstruction:** Recover database schemas (.fdb / .gdb) and rebuild the user experience.
- 🤝 **Community:** Connect retrocomputing enthusiasts and developers interested in legacy software.

### 🛠️ Structure

| Folder | Description |
| :--- | :--- |
| `bin/` | Original executables, DLLs, and components. |
| `docs/` | Technical documentation, logs, and recovered manuals. |
| `sql/` | Database scripts, UDFs, and table mapping. |
| `history/` | Screenshots, stories, and community memories. |

### 🚀 How to Contribute
Your help is vital to ensure this memory isn't lost!

1.  **Old Files:** If you have an old hard drive with Pegajogo folders, look for `.fdb`, `.gdb` files, or the original installer.
2.  **Technical Analysis:** Help map DLL functions or the SQL table structures.
3.  **Memories:** Do you have screenshots or stories about using the software? Add them to the `history` folder.
4.  **Issues:** Open an issue to discuss emulation or preservation ideas.

### 💡 Why It Matters
Software preservation is cultural preservation. Pegajogo was the gateway to the gaming world for many Brazilians. Studying how it worked—from local database management to Flash integration—is a history lesson in Brazilian software engineering.
